\# Projeto Front-end



\## Sobre o projeto



Este repositório contém um projeto desenvolvido para a disciplina de Desenvolvimento Front-end para Web.



O objetivo do projeto é aplicar conhecimentos de desenvolvimento de páginas web, utilizando tecnologias fundamentais do desenvolvimento front-end.



\## Tecnologias utilizadas



\- HTML5

\- CSS3



\## Objetivo do repositório



Este repositório foi criado para organizar, versionar e apresentar o desenvolvimento do projeto, utilizando o Git e o GitHub.
